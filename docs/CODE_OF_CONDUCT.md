# Kodeks postępowania

Projekt jest jednoosobowy, ale repozytorium jest publiczne, więc obowiązuje prosta zasada:
w zgłoszeniach, pull requestach i dyskusjach zachowujemy się wobec siebie przyzwoicie.

- Krytykujemy kod i decyzje, nie ludzi.
- Nie zakładamy złej woli tam, gdzie wystarczy nieporozumienie.
- Nie ma miejsca na obelgi, nękanie, treści seksualne ani ataki na czyjąkolwiek tożsamość.
- Rozmawiamy po polsku albo po angielsku, jak komu wygodniej.

Nieprzestrzeganie tych zasad kończy się usunięciem komentarza, a przy powtórce zablokowaniem konta
w repozytorium. Decyduje właściciel repozytorium.
